# 📦 Installation

## IrisCord / BetterDiscord

### Manual Installation

1. Download the theme file
2. Move it to your themes folder

```txt
BetterDiscord/themes
```

3. Enable the theme inside IrisCord or BetterDiscord

# 🎨 Customization

You can customize the theme directly inside the `:root` section.

```css
:root {

	--iris-emoji-scale: 1;
	--iris-emoji-hover-scale: 1.12;

	--iris-transition-speed: 0.18s;

	--iriscord-accent: #7c5cff;

}
```
