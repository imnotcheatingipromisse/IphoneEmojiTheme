# 📱 IrisCord Apple Emojis

Transform Discord’s default emoji style into beautiful native-style Apple emojis inside IrisCord.

---

## ✨ Features

* 🍎 Replaces default Discord emojis with Apple emojis
* ⚡ Smooth hover animations
* 🎨 Enhanced emoji picker styling
* 💬 Improved reaction visuals
* 🌙 Full dark/light mode support
* 🚀 Optimized rendering & performance
* 🧩 Easy to customize
* 💜 Built for IrisCord

# 📦 Installation

## BetterDiscord / IrisCord

1. Download the theme file
2. Move it into your themes folder
3. Enable the theme inside IrisCord or BetterDiscord

---

# 🛠 Supported Emoji Provider

Currently supported:

* 🍎 Apple

More providers may be added in future updates.

---

# 🎨 Customization

You can customize the theme directly from the `:root` section.

```css
:root {

	--iris-emoji-scale: 1;
	--iris-emoji-hover-scale: 1.12;

	--iris-transition-speed: 0.18s;

	--iriscord-accent: #7c5cff;

}
```
